# 2026-10-28 — 필드 검증과 정상 종료 확인

목표: 출력값을 shell 정보와 비교하고, Ctrl-C 뒤 loader가 attach한 BPF link가 정리되는지 확인한다.

```mermaid
flowchart TD
    run([execmon 실행 중]) --> shell[터미널 B에서<br/>PID·PPID·UID 확인]
    shell --> execute[/usr/bin/id 실행]
    execute --> event[execmon 출력 이벤트 확인]
    event --> compare{UID·file이<br/>실행 정보와 맞는가?}
    compare -- 아니오 --> evidence[출력·ps 결과·환경 기록]
    compare -- 예 --> interrupt[터미널 A에서 Ctrl-C]
    interrupt --> handler[signal handler가 exiting = 1]
    handler --> poll[ring_buffer__poll 루프 종료]
    poll --> free[ring_buffer__free]
    free --> destroy[execmon_bpf__destroy<br/>link·object 정리]
    destroy --> inspect[bpftool link/prog show로 관찰]
    inspect --> clean{관련 link가<br/>남아 있지 않은가?}
    clean -- 예 --> done([정상 종료 검증 완료])
    clean -- 아니오 --> error([원문 로그를 오류 파일에 기록])
```

## 주의

`bpftool` 목록에는 시스템의 다른 BPF 프로그램도 보일 수 있다. 이 단계는 관찰만 하며, 이름만 보고 다른 프로그램을 삭제하지 않는다.
