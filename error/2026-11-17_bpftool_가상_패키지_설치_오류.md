# Ubuntu 24.04 `bpftool` 가상 패키지 설치 오류

작성일: 2026-11-17

## 증상

Ubuntu 24.04 실습 VM에서 다음 설치 명령을 실행했을 때 APT가 `bpftool`의 설치 후보를 찾지 못했다.

```text
Package bpftool is a virtual package provided by:
  linux-tools-common 6.8.0-149.149
  linux-lowlatency-tools-common 6.8.0-31.31.1
E: Package 'bpftool' has no installation candidate
```

실행 중인 커널은 `6.8.0-147-generic`이다.

## 실행한 명령

```bash
sudo apt install -y \
  clang llvm libbpf-dev libelf-dev zlib1g-dev \
  linux-tools-common linux-tools-$(uname -r) linux-headers-$(uname -r) \
  build-essential pkg-config git \
  bpftrace bpftool
```

## 확인된 사실

- Ubuntu 24.04의 현재 APT 메타데이터에서 `bpftool`은 독립 패키지가 아닌 가상 패키지로 표시됐다.
- `linux-tools-common`과 커널 버전별 `linux-tools-$(uname -r)` 패키지는 별도로 설치 대상에 포함되어 있다.
- Linux 6.8 커널은 현재 `execmon`의 최소 커널 요구사항인 Linux 5.11 이상이다.

## 원인

APT가 가상 패키지 `bpftool`의 제공자를 자동 선택하지 못했다. 설치 목록에 `bpftool`을 독립 패키지처럼 넣은 것이 직접 원인이다.

## 해결 조치

- 설치 명령에서 `bpftool`을 제거했다.
- `linux-tools-common`과 `linux-tools-$(uname -r)` 설치 후 `bpftool version`으로 실제 실행 파일을 확인하도록 안내했다.
- `guide.md`와 `server_setup_guide.md`의 설치 명령도 같은 방식으로 수정했다.

## 후속 확인 항목

- `apt-cache policy linux-tools-$(uname -r) linux-headers-$(uname -r)`에서 현재 커널 6.8.0-147용 후보가 있는지 확인한다.
- 패키지 설치 뒤 `bpftool version`, `clang --version`, BTF·ring buffer·helper probe를 실행한다.
