# 2026-10-12 — `bpftool` 설치 오류

## 증상

Ubuntu 20.04 LTS(Focal), 커널 `5.4.0-216-generic`에서 아래 설치 명령을 실행했다.

```bash
apt install -y \
  bpftrace bpftool \
  clang llvm libbpf-dev libelf-dev zlib1g-dev \
  linux-tools-common linux-tools-$(uname -r) linux-headers-$(uname -r) \
  build-essential pkg-config git
```

APT가 다음 오류로 중단됐다.

```text
E: Unable to locate package bpftool
```

## 원인

Ubuntu 20.04에서는 `bpftool`이 독립 APT 패키지로 제공되지 않는다. `linux-tools-common` 패키지가 `bpftool` 실행 파일을 제공하는 패키지 구조다.

이미 확인된 상태:

- OS: Ubuntu 20.04 LTS (Focal Fossa)
- 커널: `5.4.0-216-generic`
- `linux-tools-common`: 설치됨 (`5.4.0-216.236`)
- `apt-cache search bpftool`: 결과 없음 — 이 환경에서는 정상

## 해결 조치

`bpftool`만 설치 목록에서 빼고 나머지 개발 도구를 설치했다.

```bash
apt install -y \
  bpftrace \
  clang llvm libbpf-dev libelf-dev zlib1g-dev \
  linux-tools-common linux-tools-$(uname -r) linux-headers-$(uname -r) \
  build-essential pkg-config git
```

## 후속 확인

아래 명령으로 `bpftool`의 실제 위치와 동작을 확인한다.

```bash
dpkg -L linux-tools-common | grep -E '/bpftool$'
/usr/sbin/bpftool version
```

## 관련 주의 사항

현재 커널 5.4는 이 프로젝트 가이드의 기본 이벤트 전달 방식인 `BPF_MAP_TYPE_RINGBUF`를 지원하지 않는다. ring buffer는 Linux 5.8부터 도입됐다.

- `bpftrace`를 사용한 eBPF 기초 관찰은 우선 진행 가능하다.
- CO-RE/BTF 사용 가능 여부는 `/sys/kernel/btf/vmlinux`로 별도 확인한다.
- guide.md의 CO-RE + ring buffer 기반 `execve` 모니터를 그대로 구현하려면 Ubuntu 22.04 이상(권장: 24.04, 6.x 커널) 환경을 권장한다.
