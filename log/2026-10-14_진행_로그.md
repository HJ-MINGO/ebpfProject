# 2026-10-14 진행 로그

## 추가 작업

- Java 개발 경험을 기준으로 `execmon/src/execmon.h`, `execmon/src/execmon.bpf.c`, `execmon/src/execmon.c`에 학습용 한국어 주석을 보강했다.
- 공용 구조체(DTO), C 포인터와 고정 길이 배열, eBPF verifier/helper, ring buffer, CO-RE, skeleton, callback, signal 처리와 리소스 해제를 Java 개념과 연결해 설명했다.
- **확인된 사실:** 주석 변경만 했으며, 아직 Linux 대상 빌드나 실행은 수행하지 않았다.

## 오늘의 목표

가이드 4~6단계에 따라 CO-RE 기반 `execve` 모니터의 프로젝트 구조와 첫 소스 코드를 작성한다.

## 완료한 작업

- 저장소에 `execmon/` 학습용 프로젝트 디렉터리를 만들었다.
- eBPF 프로그램과 사용자 공간이 공유하는 `src/execmon.h` 이벤트 구조체를 작성했다.
- `tracepoint/syscalls/sys_enter_execve`에서 PID, PPID, UID, 프로세스 이름, 실행 파일 경로를 수집하는 `src/execmon.bpf.c`를 작성했다.
- generated skeleton을 load/attach하고 ring buffer 이벤트를 사람이 읽을 수 있는 행으로 출력하는 `src/execmon.c`를 작성했다.
- 민감할 수 있는 `argv`, `envp`는 첫 구현의 수집 대상에서 제외했다.
- 대상 커널에서 생성해야 하는 `src/vmlinux.h`와 빌드 산출물은 `.gitignore`에 추가했다.

## 현재 상태

- 소스 작성 단계만 완료했다. 이 Windows 작업 공간에서는 Linux eBPF 빌드·실행 검증을 할 수 없다.
- 실제 실습 서버는 Linux 5.4이므로 ring buffer 기반 소스를 그대로 실행할 수 없다.
- Linux 5.8 이상인 별도 VM에서 이 기준 구현을 빌드·검증하거나, 현재 서버용 perf event array legacy 변형을 다음 단계에서 작성해야 한다.
