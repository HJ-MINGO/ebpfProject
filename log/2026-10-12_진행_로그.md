# 2026-10-12 진행 로그

## 오늘의 목표

eBPF 학습 및 단일 Linux 서버 모니터링 프로그램 개발을 위한 문서와 개발 환경을 준비한다.

## 완료한 작업

- eBPF/Falco/Kubernetes 런타임 보안 정리 문서를 작성했다.
  - `ebpf_falco_k8s_runtime_security.md`
- 단일 Linux 서버에서 `execve` 이벤트를 관찰하는 eBPF 개발 가이드를 작성했다.
  - `guide.md`
- 학습자 페르소나, 단계적 실습, 안전 원칙을 담은 프로젝트 지침을 작성했다.
  - `AGENTS.md`
- Ubuntu 20.04 서버에서 eBPF 개발 도구 설치를 시도했다.
- 독립 `bpftool` 패키지 오류를 확인하고, 해당 항목을 제외한 설치를 완료했다.

## 현재 서버 환경

- OS: Ubuntu 20.04 LTS (Focal Fossa)
- 커널: `5.4.0-216-generic`
- 설치 완료: `bpftrace`, `clang`, `llvm`, `libbpf-dev`, `libelf-dev`, `zlib1g-dev`, `linux-tools-common`, 현재 커널용 linux-tools/headers, build-essential, pkg-config, git

## 아직 확인하지 않은 항목

- `/usr/sbin/bpftool version` 실행 결과
- `/sys/kernel/btf/vmlinux` 존재 여부(BTF 지원)
- BPF JIT와 eBPF feature 지원 상태
- `bpftrace`로 `sys_enter_execve` tracepoint를 실제 관찰할 수 있는지
