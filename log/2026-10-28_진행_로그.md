# 2026-10-28 진행 로그

## 완료 작업

- 별도 eBPF 실습 VM을 생성하기 위한 서버 사양·설치·보안 설정 가이드를 server_setup_guide.md에 작성했다.
- 권장 사양을 최소치보다 한 단계 높은 2 vCPU, 4 GiB RAM, 30 GiB SSD로 정했다.
- 현재 execmon 소스의 최소 커널 요구사항(Linux 5.11, BTF, ring buffer, bpf_get_current_task_btf())을 서버 점검 명령과 체크리스트에 반영했다.
- SSH 공개키 인증, 전용 계정, 방화벽 IP 제한, root/비밀번호 로그인 비활성화 순서를 기록했다.
- 30 GiB 실습 VM을 기준으로 EFI 512 MiB, `/boot` 1 GiB, LVM root 18 GiB, `/home` 7 GiB, swap 2 GiB 및 LVM 여유 공간을 두는 파티션 구성을 추가했다.
- 서버 생성 뒤의 기본 OS 설정(호스트 이름, 시간대, NTP), SSH 서비스 확인, 보안 업데이트, 자동 업데이트 상태 확인 단계를 보강했다.
- SSH 키 인증의 private key/public key/authorized_keys 역할, `.pem` 파일과 OpenSSH 키의 관계, Ed25519 키 생성, cloud PEM에서 public key를 추출하는 방법, VS Code Remote-SSH의 `IdentityFile` 설정을 추가했다.
- 4번 절 앞에 개발 PC와 서버의 역할 표 및 3단계 실행 순서를 추가하고, 각 SSH 키·등록·접속·하드닝 명령에 실행 위치를 명시했다.
- `ssh-key-auth-guide.md`를 기준으로 4.2~4.7을 Windows PowerShell과 Ubuntu 서버 명령으로 전면 교체했다. 키 원리 설명인 4.1은 유지했고, 공개키 등록은 기존 키를 보존하는 `mkdir`·`touch`·`chown`·`chmod`·`nano` 방식으로 통일했다.
- `nano`에서 공개키 붙여 넣기, `Ctrl+O` 저장, `Enter` 파일명 확인, `Ctrl+X` 종료 및 저장 후 public key 확인 절차를 4.4에 추가했다.

## 확인된 사실

- ring buffer는 Linux 5.8부터지만, 현재 소스가 쓰는 bpf_get_current_task_btf() helper는 Linux 5.11부터 제공된다.
- Ubuntu 24.04 LTS는 현재 소스 요구사항보다 새 커널 계열을 사용하며 2029년 5월까지 표준 보안 유지보수 대상이다.

## 미확인 항목

- 사용자가 생성할 VM의 실제 커널, BTF, tool package, 네트워크 정책은 아직 확인하지 않았다.
