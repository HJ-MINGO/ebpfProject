# 2026-10-25 진행 로그

## 완료 작업

- 사용자가 서버 구성은 직접 진행하기로 했으므로, 서버 설치 절차를 제외한 `execmon`의 날짜별 테스트 시나리오를 작성했다.
- `scenario/2026-10-25_execmon_테스트_시나리오.md`에 2026-10-25부터 2026-10-30까지의 BTF/ring buffer 확인, 빌드, 최소 기능, 종료 정리, 제한 부하, 회고 단계를 정리했다.
- 각 날짜별 흐름을 Mermaid로 분리한 Markdown 파일 6개와 인덱스 `scenario/flows/README.md`를 추가했다.
- 전체 흐름의 Archify workflow 명세는 `scenario/archify/execmon_테스트_워크플로우.json`에 작성했다.
- 날짜별 시나리오·Mermaid 흐름도·현재 C 소스를 교차 검증했다.

## 확인된 사실

- 현재 `execmon` 소스는 `BPF_MAP_TYPE_RINGBUF`를 사용하므로 Linux 5.8 이상 커널이 필요하다.
- 현재 소스는 ring buffer 예약 실패를 세는 드롭 카운터를 아직 구현하지 않았다.
- `sys_enter_execve`에서는 `comm`이 대상 실행 파일의 이름으로 바뀌기 전 값일 수 있다.
- 현재 `execmon` 전체 소스의 최소 커널은 Linux 5.11이다. ring buffer는 Linux 5.8부터지만 PPID 수집 helper `bpf_get_current_task_btf()`가 Linux 5.11부터 필요하다.

## 미확인 항목

- 새 실습 VM의 실제 커널, BTF, ring buffer, 도구 버전과 빌드 결과는 아직 확인하지 않았다.
- **환경 제약:** Archify의 workflow renderer는 현재 실행 환경에서 자식 Node 프로세스 시작이 `EPERM`으로 거부되어 HTML 렌더·시각 검증을 수행하지 못했다. Mermaid Markdown 파일은 생성만 했으며, 지원 뷰어에서의 렌더 결과는 아직 확인하지 않았다.
